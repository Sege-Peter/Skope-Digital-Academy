Congratulations on reaching the end of the course! You now know more about learning than most people ever get taught at school. More importantly, you can use these methods for every skill you learn from now on.

## The big ideas

| Idea | In one sentence |
|---|---|
| Learning is a skill | Your ability grows with the right practice and methods |
| Memory | Working memory is small; long-term memory is large; attention, meaning, recall, review and sleep help memories last |
| Two modes | Switch between focused work and relaxed breaks; start hard tasks early |
| Active recall | Test yourself instead of re-reading |
| Spaced repetition | Review over several days, with growing gaps |
| Notes | Short, in your own words, with questions to test yourself (Cornell) |
| Procrastination | Make starting easy; use Pomodoros and remove distractions |
| Online learning | Pause and do, build projects, ask good questions, avoid scams |
| Motivation | Know your why, set small goals, use a growth mindset, expect the dip |
| Learning plan | One skill, clear goal, routine, projects, weekly review |

## Using this in your next course

Here is how a single study session might look now:

1. **Before:** Quickly recall what you learned last time (2 minutes, no notes).
2. **During:** One or two Pomodoros on the new lesson. Pause videos to practise. Take Cornell notes.
3. **After:** Close the notes and write the main points from memory. Make 3–5 flashcards.
4. **Later:** Review the flashcards over the next days and weeks.
5. **Weekly:** Build something small and review your plan.

> **Tip:** Go back to the [personal learning plan](personal-learning-plan) lesson in a month and update your plan. Learning how to learn is itself something you keep improving.
