Fast typists don't only type quickly; they also avoid reaching for the mouse. **Keyboard shortcuts** let you copy, paste, save, switch windows and move around documents without taking your hands off the keys. Learning even ten of them can save you many minutes every working day.

The shortcuts below are for **Windows** computers, which are the most common in Kenyan offices and cyber cafés. On a **Mac**, use the **Cmd** key instead of **Ctrl** for most of them.

## The essential ten

| Shortcut | Action |
|---|---|
| Ctrl + C | Copy |
| Ctrl + X | Cut |
| Ctrl + V | Paste |
| Ctrl + Z | Undo the last action |
| Ctrl + Y | Redo |
| Ctrl + S | Save |
| Ctrl + A | Select all |
| Ctrl + F | Find a word on the page or in the document |
| Ctrl + P | Print |
| Alt + Tab | Switch between open windows |

> **Tip:** Press **Ctrl + S** every few minutes while you work. A power cut or a crashed program can wipe out an hour of typing that was never saved.

## Moving and selecting text

These work in Word, Google Docs, email and most text boxes.

| Shortcut | Action |
|---|---|
| Ctrl + Left or Right arrow | Jump one word at a time |
| Home / End | Go to the start or end of the line |
| Ctrl + Home / Ctrl + End | Go to the start or end of the whole document |
| Shift + arrow keys | Select text character by character |
| Ctrl + Shift + Left or Right arrow | Select a word at a time |
| Ctrl + Backspace | Delete the whole previous word |

**Ctrl + Backspace** is especially useful when you make a typing mistake: one press removes the whole wrong word, and you retype it, often faster than pressing Backspace eight times.

## Formatting

| Shortcut | Action |
|---|---|
| Ctrl + B | Bold |
| Ctrl + I | Italic |
| Ctrl + U | Underline |
| Ctrl + Shift + V | Paste without formatting (in many browsers and Google Docs) |

Pasting without formatting is handy when you copy text from a website into a report and don't want its fonts and colours.

## Browser shortcuts

| Shortcut | Action |
|---|---|
| Ctrl + T | Open a new tab |
| Ctrl + W | Close the current tab |
| Ctrl + Shift + T | Reopen the tab you just closed |
| Ctrl + Tab | Move to the next tab |
| Ctrl + L | Jump to the address bar |
| Ctrl + plus / minus | Zoom in or out |
| Ctrl + 0 | Reset zoom |

## Windows shortcuts

| Shortcut | Action |
|---|---|
| Windows key + D | Show the desktop |
| Windows key + E | Open File Explorer |
| Windows key + L | Lock the computer (do this when you leave your desk) |
| Windows key + V | Clipboard history (after you turn it on) |
| Windows key + Shift + S | Take a screenshot of part of the screen |

> **Warning:** In shared places like cyber cafés and offices, always lock (Windows key + L) or log out when you step away, and never let the browser save your passwords on a shared computer.

## Shortcuts in spreadsheets

Data-entry jobs often use Excel or Google Sheets:

| Shortcut | Action |
|---|---|
| Tab | Move to the next cell to the right |
| Enter | Move to the cell below |
| Ctrl + arrow key | Jump to the edge of the data |
| Ctrl + D | Fill down (copy the cell above) |
| F2 | Edit the current cell |

## How to learn shortcuts without stress

Don't try to memorise all of them in one day. Pick **three new shortcuts each week**, write them on a small note next to your screen, and force yourself to use them instead of the mouse. After a week they become automatic; then add three more.

```exercise
Q: Fill in the shortcut letter for Undo.
Ctrl + ___
A: z
H: The last letter of the alphabet.
```

```exercise
Q: Fill in the keys that switch between open windows.
___ + Tab
A: alt
H: It is next to the space bar.
```

```exercise
Q: Complete the shortcut that deletes the whole previous word.
Ctrl + ___
A: backspace
H: The key you normally use to delete one character.
```

## Practice task

Open a document and a web browser. Without touching the mouse, do this: write three sentences about your town, make one word bold, select all the text, copy it, switch to the browser with Alt + Tab, open a new tab, switch back and save the document. Repeat until you can do it smoothly, then choose your three shortcuts for this week.
