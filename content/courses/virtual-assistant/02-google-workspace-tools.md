Most VA work happens inside a small set of online tools. The most common are Google's free tools, which many businesses use through a paid package called **Google Workspace**. If you have a Gmail account, you can practise with all of them for free today.

## The core Google tools

| Tool | What it does | VA uses |
|---|---|---|
| **Gmail** | Email | Managing the client's inbox, sending replies |
| **Google Calendar** | Schedules and events | Booking meetings, setting reminders |
| **Google Drive** | Online file storage | Keeping and sharing client files |
| **Google Docs** | Word processing | Letters, reports, meeting notes |
| **Google Sheets** | Spreadsheets | Data entry, lists, simple calculations |
| **Google Forms** | Online forms and surveys | Collecting bookings, feedback, registrations |
| **Google Meet** | Video calls | Client meetings and check-ins |

Some clients use Microsoft tools instead (Outlook, Word, Excel, Teams, OneDrive). The skills are very similar, so if you learn Google well you can adapt quickly.

## Google Drive: organise like a professional

Clients judge you by how tidy their files are. Use a clear folder structure and file names.

```text
Client – Baraka Hardware/
  01 Admin/
  02 Invoices/
    2026-03 Invoices/
  03 Stock Lists/
  04 Marketing/
```

Good file names include **what** it is and a **date**:

| Poor name | Good name |
|---|---|
| Document1 | Supplier list – Kisumu – 2026-03-10 |
| final final2 | Weekly report – week 11 – 2026 |
| IMG_4432 | Poster – Easter offer – v2 |

> **Tip:** Writing dates as year-month-day (2026-03-10) makes files sort in the right order automatically.

## Sharing files correctly

Every Google file has a **Share** button. Choose the right permission:

- **Viewer** – can only look. Use for finished reports.
- **Commenter** – can add comments but not change the text. Use for drafts you want feedback on.
- **Editor** – can change everything. Use only for people who really need to edit.

Be careful with "Anyone with the link". Anyone who gets the link can open the file. For private client documents, share only with specific email addresses.

> **Warning:** Never move a client's files to your personal accounts or download them to shared computers (like a cyber café) without permission. If you must use a shared computer, log out completely and do not save passwords.

## Google Docs and Sheets basics to practise

**Docs**
- Use **Headings** (Format → Paragraph styles) so documents look tidy and get an automatic outline.
- Use **Suggesting** mode to propose edits the client can accept or reject.
- Use **comments** to ask questions inside the document.

**Sheets**
- **Freeze** the top row (View → Freeze) so headings stay visible.
- Use **filters** to sort and find data.
- Learn a few formulas, for example:

```text
=SUM(B2:B20)      adds the numbers in B2 to B20
=AVERAGE(B2:B20)  finds the average
=COUNTA(A2:A20)   counts cells that are not empty
```

## Two-step verification

Turn on 2-step verification on your Google account (in your Google Account security settings). If a client gives you access to their account, ask how they want you to log in safely – many use shared access or a password manager rather than sending passwords on WhatsApp.

```exercise
Q: Fill in the right sharing permission.
For a draft that the client should only comment on, choose ___. For a finished report, choose ___.
A: Commenter / comment | Viewer / view
H: One lets people add notes; the other only lets them look.
```

```exercise
Q: Complete the formula that adds the numbers in cells B2 to B20.
=___(B2:B20)
A: SUM
H: A three-letter word meaning "total".
```
