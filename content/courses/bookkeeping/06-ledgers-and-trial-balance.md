After recording debits and credits, a bookkeeper **posts** them to the **ledger** – the collection of all the business's accounts. Then a **trial balance** checks that the debits and credits still agree.

## T-accounts

Each ledger account is often drawn as a "T": debits on the left, credits on the right. Here are Brian's accounts from the last lesson ([Double-entry basics](double-entry-basics)), shown as tables.

**Cash account**

| Date | Debit (in) | KES | Date | Credit (out) | KES |
|---|---|---|---|---|---|
| 1 Mar | Capital | 20,000 | 2 Mar | Purchases | 8,000 |
| 5 Mar | Sales | 12,000 | 10 Mar | Rent | 3,000 |
| | | | 31 Mar | Balance carried down | 21,000 |
| | **Total** | **32,000** | | **Total** | **32,000** |
| 1 Apr | Balance brought down | 21,000 | | | |

To **balance** an account: add the bigger side (32,000), subtract the smaller side (11,000), and write the difference (21,000) on the smaller side so both totals match. The balance is then brought down on the opposite side to start the next month. Cash has a **debit balance** of KES 21,000 – the money Brian should have.

**Other accounts (balances only)**

| Account | Entries | Balance |
|---|---|---|
| Capital | Cr 20,000 | Credit 20,000 |
| Purchases | Dr 8,000 + Dr 5,000 | Debit 13,000 |
| Sales | Cr 12,000 | Credit 12,000 |
| Rent | Dr 3,000 | Debit 3,000 |
| Wanjiku Wholesalers | Cr 5,000 | Credit 5,000 |

## The trial balance

A **trial balance** lists every account balance in two columns on a given date.

**Brian's Shop – Trial balance at 31 March**

| Account | Debit (KES) | Credit (KES) |
|---|---|---|
| Cash | 21,000 | |
| Purchases | 13,000 | |
| Rent | 3,000 | |
| Capital | | 20,000 |
| Sales | | 12,000 |
| Wanjiku Wholesalers | | 5,000 |
| **Totals** | **37,000** | **37,000** |

The totals agree, so the double entry was done consistently.

## What a trial balance can and cannot catch

| Catches | Does **not** catch |
|---|---|
| A debit posted without its credit | A transaction left out completely |
| An amount written differently on each side (e.g. 5,000 and 500) | A transaction posted to the wrong account but on the correct side |
| Addition mistakes in an account | Both sides recorded with the same wrong amount |

> **Tip:** If the totals do not agree, find the difference. If the difference divides exactly by 9, look for swapped digits (for example 5,400 written as 4,500 – the difference is 900, and 900 ÷ 9 = 100).

## From trial balance to reports

The trial balance is the starting point for the profit and loss statement and balance sheet. For Brian:

```text
Sales 12,000 − Purchases 13,000 − Rent 3,000 = −4,000 (a loss?)
```

Not necessarily! Brian probably still has unsold stock at month end. Accountants adjust for **closing stock** before working out profit – a step beyond this beginner course, but worth knowing so you do not panic at raw figures.

```exercise

```
