Almost every office job in Kenya – from a school bursar's clerk to a hotel receptionist in Naivasha – expects you to "know computer packages". That phrase usually means three programs: **Microsoft Word** for documents, **Excel** for numbers and **PowerPoint** for presentations. This course teaches all three, plus their free Google versions, and shows you how to earn money with them.

First, let us get comfortable with the machine itself.

## Hardware and software

**Hardware** is anything you can touch. **Software** is the set of instructions that makes the hardware useful.

| Part | What it does | Example |
|---|---|---|
| Monitor | Shows the picture | A 19-inch screen in a cyber café |
| Keyboard and mouse | Let you type and point | USB or wireless |
| System unit / laptop body | Holds the processor, memory and storage | Desktop tower, laptop |
| Storage | Keeps files when power is off | Hard disk, SSD, flash disk |
| Operating system | Runs the computer and other programs | Windows, macOS, ChromeOS, Linux |
| Application | Does a specific job | Word, Excel, Chrome |

> **Note:** Most computers you will meet in offices and cyber cafés in Kenya run **Windows**, so this course uses Windows examples. On a Mac, the **Command (⌘)** key usually replaces **Ctrl**.

## Starting up and shutting down

1. Press the power button once. Wait for the sign-in screen.
2. Sign in with your password or PIN.
3. When you finish, save your work, then open the **Start** menu, choose the power icon and pick **Shut down**.

Never switch off at the socket while the computer is running. You can lose unsaved work and, over time, damage files. In areas with frequent power cuts, a small **UPS** (uninterruptible power supply) gives you a few minutes to save and shut down properly.

## The desktop and taskbar

- The **desktop** is the background screen with icons.
- The **taskbar** is the strip (usually at the bottom) showing open programs.
- The **Start** button opens the list of installed programs and a search box.

The fastest way to open any program is to press the **Windows key**, type its name (for example *word*) and press **Enter**.

## Using the mouse

| Action | How | Typical use |
|---|---|---|
| Click | Press the left button once | Select an item, press a button |
| Double-click | Press the left button twice quickly | Open a file or folder |
| Right-click | Press the right button once | Show a menu of options |
| Drag | Hold the left button and move | Move a file, select text |
| Scroll | Roll the wheel | Move up and down a page |

## Your first keyboard shortcuts

Shortcuts save a lot of time. In this course they are written like **Ctrl + C**, meaning "hold Ctrl, then press C".

| Shortcut | Action |
|---|---|
| **Ctrl + C** | Copy |
| **Ctrl + X** | Cut |
| **Ctrl + V** | Paste |
| **Ctrl + Z** | Undo the last action |
| **Ctrl + Y** | Redo |
| **Ctrl + S** | Save |
| **Ctrl + P** | Print |
| **Alt + Tab** | Switch between open windows |

> **Tip:** **Ctrl + Z** is your best friend. If you delete a paragraph by mistake, undo it immediately.

## Practice task

Sit at any computer (home, school or a cyber café) and do this in 10 minutes:

1. Open three programs using the **Windows key** and search.
2. Switch between them with **Alt + Tab**.
3. Open Notepad, type your name, copy it with **Ctrl + C** and paste it five times with **Ctrl + V**.
4. Close everything and shut the computer down properly.
