Imagine a customer at your cyber café in Kisumu asks you to reprint the CV you typed for her last month. If your files are named *Document1*, *Document2* and *New folder (3)*, you will waste time searching. Good file habits make you look professional and save hours every week.

## Files and folders

- A **file** is one saved item: a letter, a photo, a spreadsheet.
- A **folder** is a container that holds files and other folders.
- **File Explorer** is the Windows program for browsing them. Open it with **Windows key + E**.

Common places on a Windows computer:

| Location | Used for |
|---|---|
| Desktop | Shortcuts you use often (do not dump everything here) |
| Documents | Letters, reports, spreadsheets |
| Downloads | Files saved from the internet and WhatsApp Web |
| Pictures | Photos and scans |
| This PC / USB drive | Flash disks and external drives |

## File extensions

The letters after the dot in a file name tell you the file type.

| Extension | Type | Opens with |
|---|---|---|
| `.docx` | Word document | Word, Google Docs, LibreOffice |
| `.xlsx` | Excel workbook | Excel, Google Sheets |
| `.pptx` | PowerPoint presentation | PowerPoint, Google Slides |
| `.pdf` | Portable Document Format | Any browser or PDF reader |
| `.jpg` / `.png` | Picture | Photos app, browser |

> **Tip:** Send final CVs and letters as **PDF**. A PDF looks the same on every phone and computer, and the reader cannot accidentally change it.

## Naming files well

Use names that say **who, what and when**:

```text
Bad:  Document1.docx
Good: Achieng-Otieno-CV-2026.docx

Bad:  budget final final 2.xlsx
Good: Shop-Budget-2026-03.xlsx
```

Avoid symbols such as `/ \ : * ? " < > |` – Windows does not allow them in file names.

## Making, renaming and moving

| Task | How |
|---|---|
| New folder | Right-click an empty space › **New** › **Folder**, or **Ctrl + Shift + N** in File Explorer |
| Rename | Select the item and press **F2** |
| Copy | **Ctrl + C**, open the destination, **Ctrl + V** |
| Move | **Ctrl + X**, open the destination, **Ctrl + V** (or drag) |
| Delete | Select and press **Delete** – it goes to the Recycle Bin |
| Select all | **Ctrl + A** |

## Save and Save As

- **Save** (**Ctrl + S**) updates the file you are working on.
- **Save As** creates a new copy, letting you choose a new name, folder or type (for example PDF). In most versions you find it under the **File** menu; **F12** opens it directly in Microsoft Office on Windows.

Save early and save often – especially before a blackout.

## Flash disks and viruses

Customers' flash disks often carry viruses. Before opening anything:

1. Make sure the computer's antivirus (Windows Security is built in) is on.
2. Right-click the drive and scan it if your antivirus offers that option.
3. Never open strange files like `photo.jpg.exe` – that is a program pretending to be a picture.
4. When finished, use **Eject** before pulling the disk out.

> **Warning:** Do not store customers' documents on a shared cyber café computer longer than needed. They may contain ID numbers and phone numbers. Delete them, and empty the Recycle Bin, once the job is done and paid for.
