## What next?

Well done for completing the tutorial. Here are some ideas to keep improving:

- Revisit the [Built-in Functions Reference](built-in-functions) and try each function in the editor.
- Build a small project: a shopping list manager, a school grade calculator or a budget tracker that saves to a CSV file (see [File Handling](files)).
- Practise reading error messages and handling them with [Try...Except](exceptions).
- Explore more of the standard library, such as `json`, `statistics` and `collections`.

> **Tip:** The best way to learn programming is to build something you care about. Start small, finish it, then make it a little bigger.
