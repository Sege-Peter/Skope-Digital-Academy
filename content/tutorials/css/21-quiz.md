Test what you have learned in this tutorial. Choose one answer for each question. If you get one wrong, revisit the lesson it comes from; the [CSS Property Reference](property-reference) is a handy summary.

```quiz
Q: What does CSS stand for?
- Creative Style Sheets
- Cascading Style Sheets *
- Computer Styling System
- Colourful Style Syntax

Q: Which is the correct way to link an external stylesheet?
- <style src="main.css">
- <stylesheet>main.css</stylesheet>
- <link rel="stylesheet" href="main.css"> *
- <css href="main.css">

Q: Which selector targets every element with class="price"?
- #price
- price
- .price *
- *price

Q: Which colour value is the same as pure white?
- #000000
- rgb(255 255 255) *
- hsl(0 0% 0%)
- #ff0000

Q: An element has width: 200px, padding: 10px and a 5px border with box-sizing: content-box. How wide is it on screen?
- 200px
- 215px
- 230px *
- 250px

Q: Which declaration centres a block element that has a fixed width?
- text-align: center;
- margin: 0 auto; *
- align: center;
- padding: auto;

Q: If the root font size is 16px, what is 1.5rem?
- 15px
- 16px
- 24px *
- 32px

Q: What is the difference between display: none and visibility: hidden?
- There is no difference
- display: none keeps the space; visibility: hidden removes it
- display: none removes the space; visibility: hidden keeps it *
- visibility: hidden only works on images

Q: An element with position: absolute is positioned relative to what?
- Always the browser window
- Its nearest ancestor that is not position: static *
- Its own normal position
- The previous sibling element

Q: In a flex container with flex-direction: row, which property spaces items along the horizontal axis?
- align-items
- justify-content *
- flex-wrap
- align-self

Q: What does grid-template-columns: repeat(3, 1fr) create?
- Three rows of equal height
- Three equal-width columns *
- One column three times wider than the others
- Three columns of 1px each

Q: Which selector has the highest specificity?
- div p
- .menu a
- #header *
- p.intro

Q: Which pseudo-element needs the content property to appear?
- ::first-line
- ::before *
- ::selection
- ::first-letter

Q: Which media query applies only to screens 768px wide or wider?
- @media (max-width: 768px)
- @media (min-width: 768px) *
- @media (width < 768px)
- @media screen-768

Q: How do you read a custom property named --brand?
- $brand
- var(--brand) *
- get(--brand)
- --brand()
```
